# Imagens e referência editorial do README

## Origem

A organização do README do FRIDAY foi inspirada no [README do vibe-coding-toolkit](https://github.com/soumatheusgomes/vibe-coding-toolkit/blob/7ef68dd7b00ddfc5cd464458855e4ab66dd2128f/README.md), de Matheus Gomes, consultado em 08/11/2026, revisão `7ef68dd7b00ddfc5cd464458855e4ab66dd2128f`.

O aproveitamento é editorial: abertura visual, atalhos, tabela por situação, seções numeradas, prompts copiáveis e ligação para evidências/documentação. Redação, exemplos e desenhos são próprios do FRIDAY, adaptados aos contratos já existentes. Nenhum SVG, trecho de prompt, badge ou comando upstream foi copiado. A consulta adicional não atualiza as revisões congeladas usadas na implementação do kit, registradas em [SOURCES](../../research/SOURCES.md) e na [proveniência](../../research/CONTENT-PROVENANCE.md).
