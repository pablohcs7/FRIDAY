# Inventário de dependências e integrações

> **FRIDAY-003 · 07/11/2026.** Inventário documental aceito no [HIL do kit](KIT-SPECIFICATION.md); desenho aprovado, bibliotecas/pins condicionais conforme o contrato. Nenhum pacote instalado.

## Fronteiras do inventário

O núcleo de instruções proposto exige um cliente capaz de ler/gravar arquivos e executar as verificações pertinentes ao projeto. Não exige Node, MCP, Python, Jira, serviços pagos ou os dois repositórios upstream para descoberta e planejamento documentais. Git é necessário para operações Git, não para descrever um pedido. O futuro CLI, por ser Node/TypeScript, possui requisitos próprios. Bibliotecas de aplicação pertencem a perfis, não às dependências do kit.

O [manifesto](source-manifest.json) fixa as duas bases e 12 upstreams opcionais consultados. O [snapshot npm](dependency-snapshot.json) registra 51 pacotes com versão publicada observada, licença declarada, `engines`, peers, dependências diretas e URL. É evidência de metadados; não é lockfile nem lista de versões selecionadas. Dependências transitivas de bibliotecas de aplicações só serão resolvidas no lock da implementação. Não há SBOM de uma distribuição FRIDAY inexistente.

## Pendências verificáveis

As licenças declaradas nos registries não substituem os textos dos pacotes distribuídos. Antes de incorporar um componente: fixar revisão/versão, resolver lock, revisar licenças e notices dos arquivos efetivamente incluídos, conferir advisories e scripts de instalação, medir plataformas suportadas e executar o cenário pretendido. Não há autorização nem necessidade de resolver árvores transitivas de todos os extras excluídos nesta tarefa. Os limites estão identificados por linha; uma futura seleção reabre somente a análise da capacidade escolhida.

Para servidores/serviços dos perfis, separar licença do cliente, licença da versão do servidor, licença de imagens e termos do hosting. Redis ilustra essa distinção: o pacote Node não define os termos do servidor; consultar a [página oficial de licenças](https://redis.io/legal/licenses/) para a distribuição selecionada. Não deduzir MongoDB, Docker Desktop, AWS ou fontes/assets a partir do MIT de um client npm.
